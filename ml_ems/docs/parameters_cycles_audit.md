## 1. 直接影响改造的结论

1. `fuel_map` 在源码中改变了单位。`parameter.m:9–38` 的原始字面表是 **g/s**，`39–42` 转换并覆盖为 **g/kWh**；保存的 `parameter.mat/fuel_map` 也是 g/kWh。直接把保存的值作为质量流量积分会产生单位错误。
2. 当前速度工况是 200 秒城市循环，400 秒郊外速度公式仍被注释；地面阻力和用电曲线各有独立的 1600 秒时间轴。参数文件不是一个已经统一采样和封装的多通道循环。
3. 当前模型文本中存在 `Time_ele/ele_map`、`Time/v_cyc` 引用，未发现 `Time_fg/fg_map` 引用。当前地面阻力输出含硬编码 `0.045`，不能只把 `fg_map` 放入新结构就声称模型使用了变阻力工况。
4. 历史 `result.mat` 的大多数日志是 **0–1500 s、7501 点、0.2 s 间隔**；同一文件所保存的 `Time/v_cyc` 只有 0–200 s。历史长时结果不能直接命名为完成的 city200 基线。其 `tout` 仅保留 1498.002–1500 s 的 1000 点，也不能用作其他日志的统一时间轴。
5. `parameter.m` 会清空工作区、关闭图窗、产生三个图窗并覆盖 `parameter.mat`；`plot_result.m` 会读入历史结果中的整套参数，并改写用于绘图的电机外特性。二者均不应直接进入批量实验调用链。

## 3. 燃油单位、地图方向与现有计算口径

源码执行的转换是：

```matlab
[NE,TE] = meshgrid(ne_map,Te_map);  % 行=转矩，列=转速
PE = NE.*TE/9549;                 % kW
fuel_gpkwh = fuel_map*3600./PE;
fuel_gpkwh(1,:) = fuel_gpkwh(2,:);
fuel_map = fuel_gpkwh;
```

原始 g/s 表范围 0–79.25。最终 BSFC 范围 205.934044665–273.930594894 g/kWh，30×28 个点均有限。静态重算结果与 `parameter.mat/fuel_map` 最大绝对差为 **0**。`fuel_map_N` 根据 `Te_max_map` 屏蔽了 352 个越外特性网格点，用于绘图；它不是适合直接全域插值的无缺失燃油代价表。

当前模型 `EMT.mdl:38670–38676` 的 `FuelConsumption` 以 `ne_map` 为行索引、`Te_map` 为列索引，使用转置表 `fuel_map'`。查表前分别将转速/转矩裁到地图边界（`38737–38749`），采用 `Interpolation-Use End Values`，再乘发动机开关和非负机械功率。功率由原始实际转速与实际转矩乘积除以 9549 得到；`38751–38756` 将该功率裁到非负区间和地图矩形上界。

体积流量计算增益为 `1/3600/0.84/1000`（`EMT.mdl:38685`），因此现有燃油密度为 **0.84 kg/L**。积分器 `22803` 及输出 `fuel_L`（`38710–38715`、`38758–38761`）累计单位为 L。

新成本函数应以明确命名的 `bsfc_g_per_kWh` 查表，再计算 `mdot_g_per_s = bsfc_g_per_kWh * Pe_kW / 3600`。若使用原始 `fuel_rate_g_per_s` 表，必须认识到“直接插值质量流量”和“插值 BSFC 后乘功率”在网格点之间通常不相同；基线复现阶段应保持原模型插值口径，不能偷偷更换。

零转矩行复制 BSFC 第二行只是避免 0/0；原模型再乘机械功率后零负载燃油仍为零。发动机空载燃油、启动燃油模型不能在本阶段凭经验补造。后续如需提升物理真实性，应作为公共模型修改另行验证。

等效燃油还缺少集中配置的燃料低热值 `LHV_fuel`、等效效率 `eta_eq` 和终端 SOC 目标。`parameter.m:209` 已明确“放电为正”；应统一 `ΔSOC=SOC_final-SOC_initial`，以及电池能量消耗为初始能量减最终能量/按定义积分的正放电净能量。不要同时用 SOC 差和功率积分重复惩罚同一电池消耗，也不要把百分数 60 当作 0–1 SOC。

- 建立显式 `load_cycle`、`validate_cycle` 与 `apply_cycle_to_model`。后者负责把真实外部信号接到原始驾驶员/动力学通道，不能仅创建一个无人读取的 `cycle` 结构。

## 6. 原始绘图脚本不适合作为指标和安全校验器

- `plot_result.m:1` 关闭全部图窗并清屏，`3` 将历史 MAT 全部变量加载到调用者；绘图过程创建 11 个图窗。新函数应接收显式结果对象和参数对象，使用可控 `Visible` 和输出目录。
- `44–45` 把 A 机转速图包络改为 ±7000 rpm、平台转矩 1100 Nm；`61–62` 把 B 机改为 ±7000 rpm。原参数 A/B 均为 ±6000 rpm、平台 1110 Nm。图上看似合法不能用来证明实际参数约束合法。
- `80–86` 会把采样的发动机绘图点 `Tep` 中超过 `Te_max_map` 的部分裁到外特性，再在 `92` 绘图。它没有改原日志，但会掩盖可视化中的过转矩点。新工作点图应标出越界点，不应先修改观测数据。
- `39–43`、`56–60`、`74–78` 的固定抽样数与统一 `N` 可能在短记录中重复同一点，也可能遗漏末端。新绘图应按各信号自身长度或按时间选择，统计指标直接使用完整日志。
- `100–101` 的 `PA/Pe`、`PB/Pe` 和 `164` 的 `Po/Pi` 存在零分母以及再生/循环功率时的符号问题；`167` 又将效率显示范围固定为 0–100%。传动效率应明确功率流方向、统计区间和能量积分定义；无定义区间返回 NaN，不能通过画图轴范围裁掉异常。
