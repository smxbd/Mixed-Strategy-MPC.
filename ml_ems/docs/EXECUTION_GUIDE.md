# 运行与结果核验指南

## 环境与入口

已实际运行的环境为 Windows、MATLAB R2024b、Simulink、Simscape 和 Deep Learning Toolbox。QP 投影还使用 Optimization Toolbox。历史目录名中的 Matlab2015b 不代表新增深度学习模型可在 R2015b 执行。

在项目根目录调用 `addpath(fullfile(pwd,'ml_ems')); startup_ml_ems;`，然后使用以下入口。不要直接运行原 parameter.m 或触发原模型的加载/停止回调。

| 入口 | 用途 |
|---|---|
| `test_core` | 单位、工况、确定性与显式不可行检查 |
| `test_result_accounting` | 版本排除、失败重试与验收字段回归 |
| `check_qp_revision` | 默认权重的 30 秒闭环和计时检查 |
| `train_residual_predictors` | 从现有分轨迹数据重新训练独立残差预测器 |
| `run_residual_main` | 残差权重预检查与三工况八方法完整主实验 |

后台运行示例：`& .\ml_ems\tools\launch_matlab.ps1 -Entry run_residual_main`。每次调用创建唯一日志目录；`results/latest_job.json` 只是最近启动指针，不能代替结果完成状态。

## 控制接口与运行频率

S-Function 接收原优化器 19 维输入、20 维物理观测和原控制器 4 维动作；输出 4 维安全处理后指令及 62 维日志。原控制器执行周期为 0.02 秒，新能量管理决策周期为 0.1 秒，非决策时刻仍每 0.02 秒检查动作。物理模型步长为 0.002 秒。

新策略采用因果历史特征，不读取真实未来测试数据。离线近似 DP 独立使用完整工况，必须以离线参考标注。MLP 为功率策略，LSTM/Transformer 为未来需求预测器，CEM 负责预测功率优化。

当前增量平衡策略保留原速度指令，以原动作构造瞬时动态余量，再重新分配功率。它依赖近似传动映射，不能等同于经过车辆标定的全动力学控制律。

## 权重和版本

默认配置仍使用 `models/trained` 中的初始权重。`run_residual_main` 显式选择 `results/residual_training_20260906_143055_b35599be/models`，并使用版本 `ems-r2024b-v6-residual-qp`。运行前会复制代码、SLX 和实际权重，并保存 SHA256 清单。

不要仅按文件夹日期混合结果。应同时核对版本、工况、方法、种子、参数扰动、停止时间、权重和源代码快照。新训练生成新的独立目录；验证集选模结果不等于测试集泛化成绩。

## 如何判读结果

- `manifest.mat`：本次配置与工况。
- `simulation.mat`：Simulink 原始输出。
- `run.mat`：统一轨迹、物理观测、指标、运行状态与验收字段。
- `status.json`：可读状态和指标。
- 批量目录 `catalog.mat`：计划与已运行项目；`results.csv/xlsx/tex` 为相应汇总。

`completed` 只表示运行达到停止时间。`acceptance.accepted` 同时要求命令约束、实际物理限制、计算预算和同工况跟踪对照通过。没有对照或未测的值不会自动判定通过。

初始化耗时单列；最大决策回调应与 0.1 秒预算比较，最大中间安全检查应与 0.02 秒预算比较。原控制器上游计算未独立计时，基线时间指标保留 NaN。整车仿真墙钟速度不等于独立控制器的实时执行能力。

油耗和等效油耗同时依赖实际行驶距离与电池净能量变化。若跟踪或距离明显不同，不得只用总油量排名。等效热值和效率属于明确声明的研究假设。

## 已知验收限制

原系统启动期在现有研究限值下也出现物理超限；当前安全层不能改变已经发生的状态，也不能保证任意状态下约束集合非空。不可行和回退会保留记录。转向 Wheel 信号尚无已验证的直接物理控制通路，不能宣称已完成转向负载泛化。初始专家数据和近似 DP 存在局限，仍需更广泛轨迹和完整闭环验证。
